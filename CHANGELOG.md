# Changelog

All notable changes to Lantern are documented here. The project follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-24

### Added

- Progressive local-network discovery with live results and scan progress.
- IP, MAC address, hostname, manufacturer, model, and best-effort device/OS identification.
- Search, filtering, network selection memory, personal device names, and saved-device highlighting.
- Saved SSH profiles with reachability indicators.
- Password storage in Windows Credential Manager, macOS Keychain, or Linux Secret Service.
- Compact tabbed terminals, multiple sessions to the same host, and collapsible navigation.
- Cross-platform release automation and native installers.
